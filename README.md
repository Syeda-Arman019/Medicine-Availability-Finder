# 💊 MediFinder – Medicine Availability Finder

## 🩺 About

MediFinder is a full-stack web application designed to help users find medicines and check their availability at nearby pharmacies. Users can search for medicines, view pharmacy details, check stock availability, and make medicine reservations through a simple and user-friendly interface.

The application combines a React frontend, Flask backend, MySQL database, REST APIs, AI chatbot, and email notifications into one platform.
